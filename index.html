Salah Calendar

A calendar that schedules around your prayers.

Most prayer apps show a timetable. Salah Calendar places the five daily prayers as real blocks inside their valid time windows, around the meetings you actually have, and re-plans whenever your day changes.

  • Two-way Google Calendar sync and cloud push reminders, built on Supabase Edge Functions
  • A constraint-based scheduling assistant that finds slots around events, prayers and protected time
  • Prayer-time engine with 15 calculation methods, tested against the adhan library
  • Offline-first PWA and Android app, 150+ automated tests

University work

FastGATr

1500× faster than naive C++ · 1.7–4.5× faster than the optimised PyTorch reference

Optimised a geometric algebra transformer on Apple M1. Exploited structure-tensor sparsity with generated kernels (about 140× fewer operations), added ILP, operator fusion and cache-aware weight repacking, and hand-vectorised the hot loops with NEON intrinsics.

  • C++
  • Python
  • ARM NEON SIMD

Cloud workload scheduling

Latency-sensitive and batch jobs sharing one cluster

Built schedulers that co-locate memcached with PARSEC batch workloads. Measured resource interference with iBench and PARSEC scalability, then used the results to schedule on a heterogeneous VM cluster (static load) and on a single machine (dynamic load).

  • Google Cloud
  • Kubernetes
  • Kops
  • Python

Bachelor Thesis: XRAY+

300,000+ automated test cases on AXI interconnects

Written at ETH Zurich's Secure and Trustworthy Systems Group. Extended XRAY, a tool for security analysis of AXI interconnects, with new execution modes and security properties, which uncovered previously unknown security vulnerabilities. Automated large-scale testing with a TCL pipeline script running over 300,000 test cases on different AXI interconnects.
